## 🚀 How to Host for FREE on Render (www.render.com)

Render allows you to host static websites 100% free with unlimited custom domains and automated HTTPS (SSL).

### Step 1: Upload to GitHub
1. Open [github.com/new](https://github.com/new) and sign in.
2. Create a new repository named `maths-special-topic-session` (set to **Public**).
3. Click **"uploading an existing file"** or extract `maths-website.zip` and drag-and-drop the files (`index.html`, `styles.css`, `app.js`, `render.yaml`, and the `assets/` folder).
4. Click **"Commit changes"**.

### Step 2: Deploy on Render
1. Go to [dashboard.render.com](https://dashboard.render.com/) and sign up or log in (choose **Sign in with GitHub**).
2. Click the blue **"New +"** button in the top right corner.
3. Select **"Static Site"**.
4. Choose the repository you created (`maths-special-topic-session`) and click **"Connect"**.
5. Configure the deployment:
   - **Name**: `maths-topic-mastery` (or any custom name)
   - **Branch**: `main`
   - **Build Command**: *(leave blank)*
   - **Publish Directory**: `./` (or `.`)
6. Click **"Create Static Site"**.

Render will deploy your site in ~30 seconds and provide a live URL like:
`https://maths-topic-mastery.onrender.com`
